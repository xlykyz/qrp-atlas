# QRP Atlas — 前端视觉设计方案

> 版本 v1.0 | 2026-07-09

---

## 问题诊断

当前界面的核心问题不是"功能缺失"，而是**视觉语言的缺失**：

| 问题 | 表现 | 影响 |
|------|------|------|
| **无品牌色** | 全界面 neutral gray 色板，sidebar 纯 `slate-900`，没有能让人记住的颜色 | 打开页面 3 秒后无法回想任何视觉特征 |
| **层级扁平** | 标题、正文、辅助文本视觉权重接近，KPI 卡片和普通卡片视觉上没有区分 | 用户找不到信息重点 |
| **缺乏呼吸感** | 间距过于均匀，`p-6` 一视同仁，没有节奏变化 | 界面压抑，阅读疲劳 |
| **数据缺乏温度** | 涨跌幅只有红绿纯色文字，没有趋势指示、没有背景渐变、没有微交互 | 数据看起来"冷"，不像在讲一个故事 |
| **Sidebar 压迫感** | 264px 宽、纯黑背景，像一个视觉黑洞 | 注意力被侧边栏吞噬 |
| **细节粗糙** | 主题切换按钮用 emoji 代替图标；标题仍是 `temp-web`；分割线无渐变 | 处处透着"能用就行" |

---

## 设计目标

从"能用"到"好用且好看"，在不改动架构的前提下，通过以下层面提升：

1. **品牌识别** — 建立 QRP Atlas 独有的视觉记忆点
2. **信息层级** — 让数据有主次、有节奏、有呼吸
3. **数据叙事** — 让数字不只是数字，而是有温度的故事
4. **细节打磨** — 间距、阴影、圆角、过渡动画，追求像素级品质
5. **双主题一致性** — 亮色/暗色都要好看，不是"暗色凑合能用"

---

## 设计方案总览

### 品牌概念

**"Atlas" = 地图集 = 导航与洞察**

将品牌定位为**专业交易者的导航系统**。视觉语言灵感来自：
- 高端航海/航空仪表盘（精密、可信）
- 现代地图学（层次清晰、色彩考究）
- Bloomberg 终端（专业感，但不那么"80年代"）

### 核心改动

```
Before:  slate monochrome  →  After:  Atlas Sapphire + Amber accent
         无品牌识别             独立品牌色系统
         均匀间距               8px 韵律系统
         冷淡数据               带温度的数据可视化
         压迫 sidebar           优雅 sidebar 带微妙渐变
         emoji 图标             lucide-react 统一图标
```
