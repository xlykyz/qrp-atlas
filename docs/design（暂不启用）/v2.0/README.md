## 设计定位

**「精准暗」（Precision Dark）**

面向 A 股量化复盘场景。数据密度高、专业感强，参考 Futu / Bloomberg Terminal 的信息层次，结合现代 Web 设计语言，打造一个「不像程序员随手堆出来」的交易仪表盘。

核心原则：
1. **暗色优先** — 深海军蓝底色，而非纯黑；减少眼疲劳，突出数字
2. **数字第一** — 等宽字体渲染所有价格/百分比，右对齐，精确到位
3. **色彩有语义** — 红涨绿跌（A 股惯例），蓝色=主要交互，琥珀=警示/注意
4. **层次靠密度** — 用背景色深浅区分层级，不依赖繁重边框和阴影
5. **动效轻量** — 150ms 过渡，只做 hover/active，不做装饰性动画

## 与现有代码的兼容说明

- 所有改动在现有技术栈（React 19 / Tailwind v4 / shadcn）内完成，**无需引入新依赖**

- 红涨绿跌色彩惯例保持不变
