# 任务 00｜外部规则基线接入与工程映射

> 状态：任务 00 工程基线
> 日期：2026-07-26
> 业务规则 SSOT：`xlykyz/MyTradingSystem`
> qrp-atlas 基线：`develop/v1.1@134b1c38af9189ac75e44a6821bc600dc4f3a96d`

## 1. 任务边界

本目录只保存 qrp-atlas 实现所需的外部来源证据、稳定规则引用、工程映射、版本集合和参数状态，不复制或重新裁决完整交易规则。

发现冲突、缺失输入或未冻结参数时，必须回到 `MyTradingSystem` 裁决；qrp-atlas 不得使用默认值补齐。

## 2. 交付物

- `01_外部规则基线清单.md`：锁定 repository、commit、document 和内容哈希；
- `02_规则登记与工程映射.md`：稳定 `rule_id`、状态、层级、输入、输出、时点、模块和测试映射；
- `03_规则版本集与参数集.md`：初始 `rule_version_set`、`parameter_set` 和参数来源；
- `04_未裁决项与禁止推断.md`：显式阻断项、占位输出和后续裁决入口。

## 3. 使用规则

1. 实现、测试、运行产物必须引用 `rule_version_set_id` 和 `parameter_set_id`；
2. `CURRENT` 规则可以进入后续契约设计，仍需按发布闸门逐级验收；
3. `DEFERRED` 规则只允许建立接口、状态和测试桩，不得形成生产交易决定；
4. `DISABLED` 规则必须通过负向测试防止等价恢复；
5. 外部 source commit 变化时创建新版本集，不覆盖本目录中的既有记录。

## 4. 任务 00 退出结论

进入任务 01 的规则均已登记来源、层级、输入、输出、计算时点和状态。评分公式、权重、M1—M3 映射、主线量化阈值等未裁决项保持显式阻断，不构成生产默认值。
