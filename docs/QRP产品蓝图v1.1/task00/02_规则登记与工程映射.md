# 规则登记与工程映射

## 1. 标识规范

规则标识采用 `SB20.<LAYER>.<NNN>`。标识只表示稳定工程引用，不替代源文档语义。`source_locator` 使用源文档标题定位，后续文案调整不得复用旧 `rule_id` 表达不同语义。

本登记表每条记录共同继承：

```text
source_repository = xlykyz/MyTradingSystem
source_commit = 82369650d16914e42c03da7635f410b12a38220e
source_document = docs/15_交易系统2.0(初稿).md
rule_version = 1
parameter_set_id = system_b_2_0_draft_1_params_1
priority = SOURCE_PRECEDENCE
```

`SOURCE_PRECEDENCE` 表示冲突必须按源文档 `0.1 规则优先级` 返回 SSOT 解释，不在 qrp-atlas 中创建另一套数值优先级。表中规则名称取“规范化工程引用”首句，备注由状态、模块和验证列共同表达。

工程映射只描述外部规则在 qrp-atlas 中的职责落位、契约输入输出和验证责任。表内摘要不得作为独立业务解释；与来源发生任何差异时，以锁定的 `MyTradingSystem` 文档为准并返回 SSOT 裁决。

状态含义：`CURRENT` 可进入后续契约；`DEFERRED` 未冻结并阻断依赖它的生产决定；`DISABLED` 明确不得实现。层级中，价格行为股票池属于 `asset_state` 客观事实，`role` 专用于评分后身份结果。
