# QRP v1.1 总体验收清单

> 本清单用于 v1.1 最终发布候选复验。  
> 任何未勾选的必须项均阻塞 v1.1 完成；“后续版本”项目不作为门禁。

## 一、范围、治理与分支

- [ ] 产品终点、生产范围和排除项已批准；
- [ ] 规则资产清单完整；
- [ ] 所有冲突已裁决或明确排除；
- [ ] System A标记为LEGACY，不进入生产授权；
- [ ] System B正式生产版本已冻结；
- [ ] System C明确不属于v1.1；
- [ ] 判断层只控制新开仓；
- [ ] 规则、参数和策略版本不可变；
- [ ] 变更控制已生效；
- [ ] 每个生产决策可追溯规则和参数版本；
- [ ] `develop/v1.1`为工作包长期集成分支；
- [ ] 所有v1.1工作包PR均面向`develop/v1.1`；
- [ ] 最终仅`release/v1.1-acceptance`面向main。

## 二、架构边界

- [ ] 核心抽象保持`contracts → indicators → strategies`；
- [ ] `execution`是qrp-atlas唯一新增顶级业务模块；
- [ ] 独立`qrp-trading`保持Windows MiniQMT边缘网关定位；
- [ ] indicators不输出交易动作；
- [ ] strategies不访问数据库、不调用backtest、execution、qrp-trading或QMT；
- [ ] backtest engine不包含System B、题材或券商知识；
- [ ] execution不重新实现策略、指标和目标组合；
- [ ] qrp-atlas不import xtquant；
- [ ] qrp-trading不实现策略、评分、目标组合和业务风险政策；
- [ ] QMT SDK类型不泄漏到QRP核心；
- [ ] QRP与qrp-trading通过版本化REST/WebSocket协议连接；
- [ ] 两个仓库不共享数据库；
- [ ] 前端只通过QRP API，不直接访问qrp-trading；
- [ ] 无循环依赖和第二套公共契约。

## 三、数据与PIT

- [ ] 任意历史交易日可生成当时全A活跃股票池；
- [ ] 上市、退市、ST、风险警示、停牌可历史查询；
- [ ] 涨跌停和价格限制语义正确；
- [ ] 严重异常交易监管事实可查询；
- [ ] 数据缺失、延迟和覆盖率显式；
- [ ] 题材、成员、角色、授权和评分遵守PIT；
- [ ] 来源、发布时间、可用时间、有效时间、观察时间和修订完整；
- [ ] 历史查询不使用当前canonical指针替代历史版本；
- [ ] 上游失败不会被解释为无信号；
- [ ] 数据水位可审计。

## 四、System B状态

- [ ] 完整生命周期已实现；
- [ ] 状态与账户持仓无关；
- [ ] 全市场逐日可复算；
- [ ] 趋势确认、运行、首次跌破、恢复、退出和重启事件明确；
- [ ] 等于MA5、缺失值、停牌和复牌语义明确；
- [ ] 多标的隔离和乱序输入确定性；
- [ ] `system_b_basic@1.0.0`兼容；
- [ ] 正式生产版本使用新code/version。

## 五、市场判断与授权

- [ ] A/B/C阶段定义完整；
- [ ] M1—M6客观组件完整；
- [ ] V规则完整；
- [ ] 状态确认和滞回明确；
- [ ] 收盘后计算并冻结；
- [ ] 只授权新增仓位；
- [ ] 输出策略级授权、否决、置信度和证据；
- [ ] 历史回放无未来函数；
- [ ] 数据不足时fail closed或显式unavailable。

## 六、动态产业—题材库

- [ ] 行业、产业链和题材分模；
- [ ] theme、version、cycle、alias完整；
- [ ] 公司—产业、题材—产业和题材—公司关系分离；
- [ ] 事实层和评分层分离；
- [ ] 来源文档、证据、反证和血缘完整；
- [ ] 生命周期和实体治理状态分离；
- [ ] 复燃创建新cycle；
- [ ] proposal/review/canonical commit完整；
- [ ] owner私有空间隔离；
- [ ] Agent默认只读且不能直写canonical；
- [ ] PIT查询、历史回放和API完整。

## 七、M1—M3身份

- [ ] M1、M2、M3定义和输入冻结；
- [ ] 身份绑定theme_cycle；
- [ ] 支持多角色和多核心；
- [ ] role eligibility与role score分离；
- [ ] 置信度、证据、反证和coverage完整；
- [ ] 首次确认、变化和失效可追溯；
- [ ] 人工/Agent只生成提案；
- [ ] 历史时点可重放。

## 八、资格、评分和组合

- [ ] eligibility与rank分离；
- [ ] 市场、题材、角色、趋势、可交易性和风险链完整；
- [ ] 硬否决不能被分数覆盖；
- [ ] 空池子合法；
- [ ] 缺失不自动按0；
- [ ] 全部候选和淘汰原因保存；
- [ ] 分数组成、coverage和版本保存；
- [ ] 排名确定性；
- [ ] 账户容量不改变股票自身评分；
- [ ] 完整目标组合生成；
- [ ] 已有持仓、新候选和退出顺序明确；
- [ ] 目标组合绑定规则、参数和数据快照。

## 九、完整系统验证

- [ ] 全市场PIT回测；
- [ ] 多个完整主线周期；
- [ ] A/B/C不同市场阶段；
- [ ] walk-forward和参数隔离；
- [ ] 参数敏感性；
- [ ] 成本和容量压力；
- [ ] 规则边际贡献；

## 十、每日运行产品

- [ ] 数据水位到订单计划可一键/定时完整运行；

## 十八、发布结论

只有所有必须项完成、正式演示可重复、仿真和小资金实盘验收通过，并获得人工授权后，才允许：

```text
release/v1.1-acceptance → main
标记 QRP v1.1
创建 tag v1.1.0 / GitHub Release
启用正式账户自动交易
进入下一版本主线
```

蓝图、单个任务、现有网关可连接或第一次代码下单成功，均不能单独满足发布条件。
