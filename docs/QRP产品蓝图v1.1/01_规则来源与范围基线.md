# 规则来源与范围基线

## 1. 唯一事实来源

System B 的业务规则唯一事实来源为：

```text
xlykyz/MyTradingSystem
```

qrp-atlas 不保存完整交易系统副本，只保存工程实现所需的规则引用、规范化标识、版本、参数和来源证据。

初始基线：

```text
source_repository = xlykyz/MyTradingSystem
source_commit = 82369650d16914e42c03da7635f410b12a38220e
source_document = docs/15_交易系统2.0(初稿).md
source_version = v0.1
source_date = 2026-07-26
```

## 3. 规则层级

规则必须唯一归属到以下某一层：


同一规则不得在多个层重复实现；需要组合时，由上层引用下层事实。

## 4. 已冻结的范围结论

- v1.1 唯一正式生产策略主线是 System B；
- System A 只保留历史研究、兼容和归因能力；
- System C 不属于 v1.1；
- 判断层只控制新增仓，不接管已有持仓退出；
- 盘中不允许临时主观下单；
- 日线价格统一采用前复权；
- 停牌日按个股实际交易日口径跳过；
- NEW_LISTING_WARMUP 纳入基础状态体系；
- 每次开仓为账户总资产的 1/8，整手向下取整；
- 同一股票最多买入两次，累计计划仓位 25%，并不得超过 30%；
- 同时持有不同股票不超过 6 只；
- 每日收盘后对候选和已有持仓统一重算；
- M1—M3 是评分结果，不是评分依据；
- 身份变化本身不触发卖出；
- 评分公式、权重和身份映射暂缓冻结。

## 5. 暂缓范围

以下内容不得被 Agent 以默认值或经验推断进入生产实现：

- 最终评分指标集合；
- 指标归一化方法；
- 各项评分权重；
- 综合分公式；
- M1—M3 映射阈值；
- 题材、节点、周期和龙头的精细评分模型；
- 自适应权重或机器学习；
- 严重异动自动下单；
- 多策略资金动态分配。

暂缓项可以建立契约、接口、占位状态和测试桩，但不得形成生产交易决定。

## 6. 变更入口

规则发生变化时：

```text
MyTradingSystem 完成裁决并提交
→ 记录新的 source_commit
→ 形成 qrp-atlas change proposal
→ 判断属于澄清、参数变化、规则版本变化或范围变化
→ 更新契约、实现和测试
→ 人工批准后生效
```

研究结果只能生成提案，不能直接修改 CURRENT 规则、参数、目标组合或订单计划。
