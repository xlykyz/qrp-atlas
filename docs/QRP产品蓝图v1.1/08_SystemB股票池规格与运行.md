# System B 股票池规格与运行

本模块只生成收盘后的日频数据产品，不实现题材映射、M1/M2/M3、评分或交易执行。

## 规则

- 高度池：连续两次收盘涨停进入自然高度结构；任意连续七个实际观察日内至少三次收盘涨停也可建立结构。确认时从首次涨停日起重建累计涨停次数 `n`、最大有效反包断板长度 `m` 和反包次数 `i`。基础状态持续 `ACTIVE` 时，高度生命周期延续至连续断板实际观察日达到 `n+5`；发生 `ACTIVE → BASE` 时当日结束。反包结构自身只接受不超过四个实际观察日的断板间隔。
- 容量池：仅 `ACTIVE` 股票可入池，且满足当日成交额排名前 100、五日实际观察日平均成交额排名前 100、流通市值不低于 300 亿元之一。一字涨停当日退出。
- 辨识度池：轮次累计涨幅不低于 30% 且轮次排名前 30，或五日/十日区间涨幅排名前 30。首次入池不要求 `ACTIVE`，也不要求同时属于高度池或容量池；已入池股票在轮次观察仍持续时保留，三项条件均失效且无轮次观察后退出。
- 三个池子独立判定，同一股票同日允许有多种 `pool_type`。

## 时间和指标

所有窗口按输入的实际交易观察序列计算，前复权价格、正式涨停标记、状态机和行情轮次由上游提供。公共特征只计算一次，排名按指标降序和 `asset_id` 升序确定性排序。辨识度只消费当日已有行情轮次观察，不读取轮次最终结束日决定历史快照。

## 生成和存储

正式入口为 `qrp-atlas-system-b-pools`，调用时必须提供已存在的绝对输入数据库和输出数据库。行情/状态输入库需要包含 `system_b_state_observation` 和 `daily_market_snapshot`，轮次表可以在同库，也可以通过 `--episode-database` 显式提供只读的 `system_b_episode` / `system_b_episode_observation` 库；可选复用 `daily_basic` 和 `zt_pool`。

权威表为 `system_b_pool_membership_daily`，粒度是 `trade_date × asset_id × pool_type`。只记录当日 `IN_POOL` 成员和当日刚退出的 `EXITED` 成员；最近一个三个池子均完成的交易日由 `system_b_pool_run` 表确定，不能用最大行情日期替代。

历史回补和单日更新共用 `build_stock_pools` 入口，先计算完整历史上下文，再按目标区间原子替换输出。失败时 staging 文件删除，旧成功输出不暴露半成品。

## 未配置规则

当前正式规则登记未给出“缩量”的定量阈值。容量纯计算可以保存其它已明确条件及 `shrink_volume: NOT_CONFIGURED`，但权威生产入口返回 `SHRINK_VOLUME_RULE_NOT_CONFIGURED`，不会创建或更新输出库，也不会写入 `COMPLETED` 完成标记。
