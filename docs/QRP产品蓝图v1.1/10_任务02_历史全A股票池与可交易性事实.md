# 任务 02：历史全 A 股票池与可交易性事实

## 一、目标

建立任意历史交易日可复现的全 A 股票池和客观可交易性事实，为全市场扫描、System B 回测、资格过滤和每日生产提供统一输入。

## 二、前置

- 任务 01 已验收；
- contracts 已定义历史证券状态、可交易性事实和数据水位；
- 现有股票信息、日线、停牌、涨跌停和 daily basic 链路可复用。

## 三、历史全 A 股票池

正式服务必须支持：

```text
build_historical_a_share_universe(trade_dates, ...)
```

每个 `(trade_date, asset_id)` 至少返回：

```text
asset_id
trade_date
exchange
board
list_date
delist_date
listing_age_days
is_listed
is_active
security_status
source_snapshot
```

范围明确：

- 上交所、深交所、北交所 A 股；
- 排除指数、ETF、基金、B 股、债券和非目标证券；
- 不使用当前活跃状态回看历史；
- 股票代码和市场映射复用 contracts；
- 空日期或空市场返回合法空集合，不扩展为未知全市场。

## 四、历史状态事实

至少覆盖：

- 正常上市；
- 新股/次新；
- ST、*ST 和其他风险警示；
- 暂停上市/退市整理（若数据源可得）；
- 退市；
- 停牌和复牌；
- 长期停牌；
- 数据缺失和不确定状态。

历史 ST 数据不足时必须显式报告 coverage 和来源边界，不得以当前名称回填历史。

## 五、可交易性事实

每日为全市场生成客观字段：

```text
has_market_bar
has_valid_ohlc
is_suspended
suspend_type
is_limit_up
is_limit_down
limit_status
is_st
is_recent_listing
listing_age_days
amount
turnover
volume_ratio
is_liquid
is_data_complete
is_severe_abnormal
tradability_coverage
```

注意：

- `is_liquid` 是按已批准指标定义计算的事实，不直接等同策略资格；
- `is_severe_abnormal` 只描述监管事实，是否构成否决由任务 07 使用；
- 是否能在下一开盘成交属于基于当时信息的计划可执行性估计，不能使用未来开盘结果。

## 六、严重异常交易监管事实

建立正式来源和标准化链路：

- 监管/交易所公告；
- 标的和适用区间；
- 触发类型；
- 发布时间和市场可用时间；
- 生效/解除；
- 来源链接和证据；
- 修订；
- 未能确定结束时的 fail-closed/人工审核状态。

不得用价格涨幅自行推断“严重异动监管”替代官方事实。

## 七、流动性与数据质量

实现可版本化客观指标，例如：

- N 日平均成交额；
- N 日成交额中位数；
- 换手和自由流通换手；
- 零成交/缺失天数；
- 有效价格覆盖；
- 可选 Amihud 等流动性指标；
- 复权和未复权数据一致性诊断。

所有阈值从参数定义读取，不在 pipeline 内硬编码策略门槛。

## 八、数据水位

每日任务输出：

```text
expected_universe_count
actual_universe_count
market_bar_coverage
stock_info_coverage
suspension_coverage
st_coverage
daily_basic_coverage
regulatory_coverage
status
diagnostics
```

水位不足时：

- 保存 `PARTIAL/FAILED`；
- 下游通过正式状态决定是否阻塞；
- 不把缺失记录视为正常、非 ST 或非停牌。

## 九、查询与产品接口

至少提供：

- 按日期/日期区间查询历史全 A；
- 查询单股历史状态；
- 查询全市场每日可交易性事实；
- 查询水位和诊断；
- 支持 DuckDB 正式读取和测试连接注入；
- 稳定排序和主键唯一。

## 十、回测与生产边界

- 回测使用历史 as_of 事实；
- 每日生产使用当日最新已确认事实；
- pipeline 不输出 `eligible`；
- 资格规则由任务 07 决定；
- 运行器不得自行用 ticker 列表绕过历史股票池后宣称全市场。

## 十一、测试

覆盖：

- 上市前/退市后不进入股票池；
- 多市场和代码规范；
- 历史 ST；
- 停牌多类型聚合不扩行；
- 涨跌停；
- 新股上市天数；
- 严重异常事实时点；
- 缺失数据和 partial 水位；
- 多日期稳定排序；
- 重复键拒绝；
- PIT 不使用未来状态；
- 数据源修订；
- 大范围性能和确定性；
- 旧 `load_stock_prices` 兼容回归。

## 十二、禁止范围

- 不定义市场阶段；
- 不计算题材；
- 不输出角色、eligible、score 或交易动作；
- 不使用当前股票名称推断全部历史状态；
- 不在查询层默默过滤 ST/停牌；
- 不实现 QMT 实时行情。

## 十三、验收

- 任意历史交易日能稳定生成全 A 股票池；
- 关键可交易性事实有明确 coverage 和 PIT；
- 下游可区分 false、unknown 和 missing；
- 全市场规模测试通过；
- 专项、全量和迁移测试通过；
- 能力矩阵与验收清单同步；
- PR 等待独立验收。
