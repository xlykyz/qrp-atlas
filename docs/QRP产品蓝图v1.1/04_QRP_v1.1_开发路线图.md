# QRP v1.1 开发路线图

> 状态：范围基线草案。  
> 原则：任务按依赖顺序执行，不并行推进主线，不以中间可用状态替代完整产品终点。

## 一、路线原则

1. 先冻结规则、范围和验收，再改运行代码；
2. 一次只推进一个正式任务或一个已批准子任务；
3. 上游契约未完成，下游不得以临时字段或口头约定开工；
4. 事实、资格、评分、决策、执行和评价严格分离；
5. 先完成历史可复算，再接每日生产；
6. 先完成券商无关交易核心，再接 QMT；
7. 先纸面和仿真，再小资金实盘；
8. 每个任务必须形成端到端测试、失败路径和验收报告；
9. 新想法通过变更控制，不直接插入当前任务；
10. 任务完成后同步能力矩阵、路线图和总体验收清单。

## 三、阶段划分

### 阶段 0：范围与规则基线

包含任务 00。

退出条件：

- 规则资产完整；
- 冲突全部裁决或明确标记为不进入 v1.1；
- System A/B/C 定位冻结；
- 判断层、资格、评分、仓位和退出边界冻结；
- 所有工作包的输入、输出和验收冻结；
- 变更控制正式生效。

### 阶段 1：标准事实与状态

包含任务 01—03。

目标：

```text
规则与生产契约
→ 历史全 A 与可交易性
→ 全市场 System B 和市场状态事实
```

退出条件：

- 任意历史交易日可生成当时全 A 股票池；
- 可交易性事实可 PIT 查询；
- System B 生命周期对全市场逐日可复算；
- 不依赖账户持仓；
- 数据缺失和停牌语义明确；
- 兼容现有基础字段和策略。

### 阶段 2：授权、题材与角色

包含任务 04—06。

目标：

```text
市场判断与授权
+ 动态产业—题材周期
+ M1/M2/M3 核心身份
```

退出条件：

- 判断层只授权新开仓且可历史回放；
- 题材库完成正式 PIT 代码链；
- 角色绑定 `theme_cycle`；
- 角色分数、置信度和证据可查询；
- 人工/Agent 变更走 proposal 和审核，不直写 canonical。

### 阶段 3：完整策略与验证

包含任务 07—08。

目标：

```text
授权 ∩ 题材 ∩ 角色 ∩ 趋势 ∩ 可交易性 ∩ 风险
→ eligible
→ score / rank
→ full portfolio target
→ complete-system validation
```

退出条件：

- eligibility 与 rank 分离；
- 空池子合法；
- 所有淘汰原因可解释；
- 目标组合确定性；
- 完整周期、walk-forward、成本、容量和规则归因通过；
- 生产配置可 replay。

### 阶段 4：每日产品

包含任务 09。

退出条件：

- 每日生产运行可从数据水位到订单计划完整执行；
- 运行包可重新打开；
- 前端解释市场授权、题材、角色、资格、评分和目标；
- 计划可冻结和取消；
- 尚不发送真实订单。

### 阶段 5：实盘执行

包含任务 10-A、10-B。

退出条件：

- 交易核心不依赖具体券商；
- 订单幂等、状态机、恢复和对账完整；
- 纸面模式通过；
- QMT 仿真查询、下单、撤单、回调和重连通过；
- 断线、部分成交、拒单和重启不产生重复订单。

### 阶段 6：生产验收

包含任务 11。

退出条件：

- 调度、监控、备份和恢复通过；
- 连续仿真运行通过；
- 受限小资金实盘通过；
- 日结对账无未解释差异；
- 全量测试、构建和安全审计通过；
- 最终验收 PR 获人工授权。

## 五、任务并行规则

主线默认串行。只有满足以下条件才允许并行：

- 两个任务不修改同一公共契约；
- 不存在输入输出依赖；
- 已指定独立负责人、分支和验收；
- 不会造成同一业务规则两套实现；
- 并行获得人工明确授权。

未经授权，不因多台开发机或多个 Agent 自动并行。

## 六、每个任务的统一退出条件

每项任务至少满足：

- 需求和边界与蓝图一致；
- 公共契约更新完整；
- 正式实现和公开导出完整；
- 单元、集成、PIT、失败路径和回归测试完整；
- 无未来函数；
- owner 隔离适用时通过；
- 稳定 reason code / diagnostic code；
- 文档、能力矩阵和验收清单更新；
- 专项测试、全量 pytest、compileall、diff check 通过；
- 涉及前端时 lint、typecheck、test、build 通过；
- 工作树干净；
- PR 未自行合并，等待独立验收。

## 七、禁止跨越的门禁

- 任务 00 未完成，不得实现正式规则；
- 任务 01 未完成，不得新增临时生产表；
- 任务 02 未完成，不得宣称全市场回测；
- 任务 05 未完成，不得把临时供应商概念标签当 canonical 题材；
- 任务 07 未完成，不得生成正式实盘订单计划；
- 任务 08 未完成，不得用单次回测结果授权实盘；
- 任务 09 未完成，不得让 trading 自行拼装策略输入；
- 任务 10-A 未完成，不得直接从策略调用 QMT；
- 任务 10-B 仿真未通过，不得接正式账户；
- 任务 11 未验收，不得宣告 v1.1 完成。
