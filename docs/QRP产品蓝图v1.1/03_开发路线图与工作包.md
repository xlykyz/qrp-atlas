# 开发路线图与工作包

> **2026-09-04 中期评估调整**：QRP v1.1 当前产品边界收敛为历史数据、PIT 数据生产、指标计算、策略运行、量化分析、回测、重放与每日策略产品。原 Task 10-A、10-B、11 所定义的 execution / qrp-trading / 仿真与小资金实盘能力不再作为 v1.1 的完成条件。原文保留并使用删除线标记，以保留设计与决策历史；相关能力可在未来以 Execution Extension 或后续版本重新评估。

调整原因：

1. **产品定位收敛**：实盘执行不是 QRP Core 作为量化研究、策略与回测平台成立的必要条件；QRP 输出稳定、可审计、可复现的目标组合即可形成完整 v1.1 产品闭环。
2. **现实约束变化**：原计划依赖 MiniQMT 作为主要实盘交易通道，但券商侧已通知 MiniQMT 交易接口自 2026 年 9 月起陆续关闭，原执行路径的现实前提已经变化。
3. **治理原则**：本次属于 `SCOPE_CHANGE`，不删除历史设计，不据此大规模重构已有基础设施；未来若恢复实盘能力，应通过独立扩展边界接入，而不重新把实盘设为 QRP Core 的发布前提。

## 2. 任务 00：外部规则基线接入与工程映射

目标：把 `MyTradingSystem` 已批准规则作为外部 SSOT 接入，而不是在 qrp-atlas 中重建一套交易系统。

交付：

- source repository / commit / document 锁定；
- 稳定 `rule_id` 和规则引用；
- 业务规则到模块、契约和测试的映射；
- CURRENT / LEGACY / DEFERRED 状态；
- 未裁决项与禁止推断项；
- 初始 `rule_version_set` 和 `parameter_set`。

退出条件：所有进入任务 01 的规则都有来源、层级、输入、输出、时点和状态。

## 3. 任务 01：正式数据契约

目标：定义“数据是什么”，不计算指标、不生成交易动作。

至少覆盖：

- 规则和参数版本；
- 个股状态与行情轮次；
- 股票池成员与出入记录；
- 题材、题材周期、关系和证据；
- 市场授权；
- eligibility / veto / score / rank；
- 策略决定与目标组合；
- production run；
- ~~order plan / intent / live order / fill；~~
- ~~网关引用和对账差异。~~

> 上述 execution 相关契约保留为早期设计记录与未来扩展空间，不再属于 v1.1 当前退出条件。

退出条件：主键、PIT、版本、owner、时区和持久化边界完整。

## 4. 任务 02：历史全 A 与可交易性事实

目标：建立任意历史交易日可重建的全 A 股票域和可交易性事实。

覆盖上市、退市、停复牌、板块、涨跌停、交易日、前复权和新股实际交易日数。

退出条件：不存在使用今天股票列表回填历史的未来函数；历史样本可确定性复现。

## 5. 任务 03：System B 状态、轮次与股票池

实现客观事实：

- NEW_LISTING_WARMUP；
- BASE / CANDIDATE / ACTIVE；
- 连续两个实际交易日线上确认；
- 连续两个实际交易日线下退出；
- 行情轮次和 `ma5_reentry_count`；
- MA10 轮次结束；
- 5 日涨停池、7 日高频涨停池；
- 高度池、容量池、辨识度池。

退出条件：状态转换、停牌、新股、复权和轮次唯一性全部有测试。

## 6. 任务 04：题材和市场结构事实

实现：

- 动态产业—题材库；
- 题材版本、周期、成员关系和证据；
- 自定义题材等权指数；
- M4 板块效应的客观输入；
- M5 人气的客观输入；
- M6 全市场及板块分层情绪事实。

退出条件：题材 canonical 与提案分离，事实层与评分层分离，历史读取遵守 PIT。

## 7. 任务 05：判断层与新增仓授权

目标：判断层只输出是否允许新增仓。

不得：

- 接管已有持仓；
- 触发平仓；
- 用授权变化重写历史持仓；
- 把主线判断等同于 M1—M6 任一单项。

退出条件：授权结果有规则版本、原因码、覆盖率、输入快照和审计记录。

## 8. 任务 06：评分接口、身份结果与排名框架

当前只实现：

- 候选与已有持仓统一输入；
- score component / snapshot / rank 契约；
- M1—M3 作为结果标签的接口；
- 显式 `NOT_CONFIGURED` / `DEFERRED` 状态；
- 可插拔 calculation version；
- 全候选和淘汰原因保存。

当前不得实现未经批准的权重、公式和身份阈值。

退出条件：无评分配置时系统明确拒绝生产开仓，不静默采用默认值。

## 9. 任务 07：System B 组合、持有与退出

实现：

- 新候选相对已有持仓评分门槛；
- 每次 1/8 总资产、整手向下取整；
- 单票最多两次、计划 25%且不超过 30%；
- 不同股票最多 6 只；
- 已有持仓每日重新评分但不因身份变化卖出；
- 连续两个实际交易日收盘低于 MA5 全部退出；
- 严重异动监管期资格变化与人工处置记录；
- 完整目标组合而非增量信号碎片。

退出条件：组合约束、同日退出与入场顺序、现金不足、不可成交和整数手均有确定语义。

## 10. 任务 08：历史验证、回放与 dry-run

覆盖：

- PIT 历史回放；
- 状态、资格、决定和目标逐层解释；
- ~~订单计划逐层解释；~~
- 参数敏感性和成本压力；
- 数据缺失与异常路径；
- shadow / dry-run，不连接真实交易权限。

退出条件：历史与每日重放可复现，未来结果仅用于评价。
