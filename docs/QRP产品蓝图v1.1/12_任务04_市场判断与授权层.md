# 任务 04：市场判断与授权层

## 一、目标

把判断层规则翻译为可历史回放、可解释、可版本化的市场阶段和策略授权系统。

判断层只回答：

> 下一交易日是否允许某策略新增仓位。

它不直接处理已有持仓退出，也不生成个股目标权重。

## 二、前置

- 任务 00、01、03 已验收；
- 判断层规则、M1—M6 和 V 规则已在任务 00 裁决；
- 市场和指数客观组件可用。

## 三、市场阶段

正式支持：

```text
A = 非主线 / 混沌
B = 主线主升
C = 退潮 / 不可交易
UNAVAILABLE = 数据不足，无法判断
```

状态输出至少包含：

```text
trade_date
market_phase
phase_changed
phase_started_at
phase_age
new_position_authorized
confidence
coverage
reason_codes
evidence_json
rule_version_set_id
parameter_set_id
calculation_version
```

## 四、M1—M6 市场结构

按任务 00 的最终定义计算：

- M1：容量核心是否存在并持续；
- M2：空间前排是否存在并持续；
- M3：辨识度标的是否存在并持续；
- M4：板块效应和扩散；
- M5：人气和注意力；
- M6：承压、分歧修复和情绪韧性。

每个 M 项必须输出：

```text
value/status
score
coverage
confidence
reason_codes
components
evidence
```

不得只存一个全局 boolean 而丢失题材、标的和证据。

## 五、V 规则

V 是主线主升授权的撤销/否决路径，必须：

- 使用已批准的连续确认规则；
- 明确核心趋势破坏、板块系统性下跌和无新领涨的计算；
- 输出触发组件和日期；
- 支持滞回，避免单日噪声；
- 不使用未来日结果；
- 不直接发出持仓卖出动作。

## 六、授权模型

输出策略级授权：

```text
strategy_code
trade_date
authorization_status
new_position_authorized
veto_reasons
valid_for_trade_date
frozen_at
expires_at
```

至少支持：

```text
AUTHORIZED
NOT_AUTHORIZED
VETOED
UNAVAILABLE
```

v1.1 正式授权对象为 System B 生产策略。旧研究策略可继续回测，但不自动获得实盘授权。

## 七、时点和冻结

- 正式判断在收盘后、数据水位通过后计算；
- 判断结果用于下一交易日；
- 盘中冻结，不因临时价格波动切换；
- 上游数据修订如发生在计划冻结后，不得静默改变当日计划；
- 需通过取消计划或正式紧急控制处理；
- 历史回测使用当时可用数据和相同冻结语义。

## 八、状态机与滞回

必须明确：

- A→B 的确认条件；
- B→C/A 的撤权条件；
- C→A/B 的恢复条件；
- 最短停留期；
- 多信号一致性；
- 数据不足时的状态；
- 人工覆盖的权限、期限和审计。

人工覆盖如被允许：

- 只能通过正式 override 记录；
- 必须有原因和 expires_at；
- 不修改原始模型输出；
- 生产授权同时保存模型结果和最终结果。

## 九、接口与持久化

提供：

- 单日和区间判断；
- 最新已冻结授权；
- 历史状态迁移；
- M1—M6 和 V 证据；
- 模型结果与最终授权；
- production run 绑定；
- API 查询和前端解释 DTO。

## 十、回测集成

- backtest runtime 按 signal date 读取判断结果；
- 不授权时禁止新增仓位，但已有持仓继续交给 System B 退出；
- 不得因 C 阶段自动清仓，除非任务 00 明确批准独立全局退出规则；
- 授权和策略决策分别保存，便于归因；
- 对比“无判断层/有判断层”的边际贡献属于任务 08。

## 十一、测试

至少覆盖：

- A/B/C 全部迁移；
- 确认和滞回；
- V 触发；
- 单日噪声不误切换；
- 数据 partial/unavailable；
- 收盘后到次日授权映射；
- 盘中冻结；
- 判断撤权不修改已有持仓动作；
- 人工 override 到期；
- PIT 和修订；
- 稳定 reason code；
- 多策略授权结构；
- API/持久化/owner（适用时）。

## 十二、禁止范围

- 不建立题材 canonical；
- 不判断 M1—M3 个股角色；
- 不做个股 eligibility 和 rank；
- 不生成目标组合；
- 不处理 QMT；
- 不把判断层写进通用回测引擎；
- 不因短期回测结果临时修改阶段定义。

## 十三、验收

- 判断层从旧单表/口头规则升级为正式版本化政策；
- 每日授权可解释、冻结和历史回放；
- 只影响新增仓位；
- 数据不足有显式状态；
- 端到端回测输入准备通过；
- 专项、全量和 PIT 测试通过；
- PR 等待独立验收。
