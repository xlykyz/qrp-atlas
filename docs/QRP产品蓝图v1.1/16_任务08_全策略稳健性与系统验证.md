# 任务 08：全策略稳健性与完整系统验证

## 一、目标

把 v1.0 已有代表性稳健性研究扩展为可用于完整 System B 生产系统的通用验证能力，验证判断、题材、角色、资格、评分、组合和现实成交的整体效果，而不是只看单个指标或一条收益曲线。

## 二、前置

- 任务 07 已验收；
- 完整策略可在历史全 A 和 PIT 输入上运行；
- 标准结果已能保存授权、资格、评分和目标。

## 三、验证对象

必须同时验证：

```text
market judgment
strategy authorization
theme lifecycle
M1/M2/M3 roles
System B state
eligibility/veto
score/rank
portfolio target
execution constraints
```

任何只替换其中一层的实验必须明确固定其他层版本。

## 四、样本与周期

至少覆盖：

- 多个完整主线周期；
- 主线启动、主升、分歧、退潮和沉寂；
- 无共识主线；
- 极端一九分化；
- 指数强、个股弱；
- 小票/大票风格变化；
- 高波动和流动性收缩；
- 题材复燃的新 cycle；
- 当前系统形成后的样本外区间。

周期划分必须 PIT、版本化且不由未来收益反推。

## 五、通用 walk-forward

实现可复用：

- rolling/expanding train；
- validation 选择；
- test OOS；
- step、gap 和 purge（适用时）；
- 候选参数集；
- 明确选择指标；
- 选择失败不回退到默认值；
- test 期间不重新选择；
- 多 fold 结果链式组合；
- 每 fold 独立初始账户或明确继承口径。

生产规则结构不通过自动参数优化改变。

## 六、参数敏感性

验证：

- MA/确认窗口；
- 市场授权阈值；
- 题材强度与 coverage；
- 角色阈值；
- 分数权重；
- 最大持仓数；
- 单票权重；
- 题材集中度；
- 现金缓冲；
- 已批准退出/保护参数。

输出：

- 参数邻域稳定性；
- 最优点是否尖锐；
- 不同周期一致性；
- 样本外退化；
- 成本后表现；
- 推荐生产参数集及不确定性。

## 七、成本与容量压力

至少重跑：

- 佣金；
- 最低佣金；
- 印花税；
- 滑点；
- 开盘价格偏差；
- 涨停买不到；
- 跌停卖不出；
- 停牌；
- 成交量参与率；
- 资金规模；
- 最大持仓数；
- 单题材集中度；
- 部分成交的近似研究模型。

成本压力必须重新执行，不得只在收益曲线上事后相减不一致成本。

## 八、规则边际贡献

对每个重要规则做受控对照：

```text
full system
minus market authorization
minus theme authorization
minus role gate
minus hard veto
minus each score family
minus portfolio concentration rule
alternative exit rule
```

输出：

- 收益、回撤、波动和换手变化；
- 尾部损失；
- 交易数量；
- 合法错过与非法错过；
- 不同市场阶段效果；
- 规则是否只在特定周期有效。

规则移除仅用于研究，不能自动修改生产版本。

## 九、错过分析

正式定义：

- `LEGAL_MISS`：因已批准资格/风险/容量规则未参与；
- `ILLEGAL_MISS`：按当时规则应进入但因数据、实现、排序或执行错误错过；
- `UNAVAILABLE_MISS`：当时数据不足，不能合理判断；
- `EXECUTION_MISS`：有正式目标但因真实不可成交未完成；
- `OUT_OF_SCOPE`：不属于策略范围。

不得用事后涨幅简单把所有未买股票定义为错过。

## 十、归因

结果至少按以下维度归因：

- 市场阶段；
- 题材和 cycle；
- M1/M2/M3；
- 入场趋势状态；
- 分数分位；
- 持仓周期；
- 退出原因；
- 交易限制；
- 成本；
- 规则版本；
- 参数集。

## 十一、基准与对照

至少比较：

- `system_b_basic@1.0.0`；
- 仅价格状态无授权版本；
- 正式完整 System B；
- 主要指数；
- 简单等权候选组合；
- 随机/确定性控制组（只用于研究合理性检查）。

## 十二、结果包

通用稳健性 artifact 至少包含：

```text
config
rule/parameter snapshots
folds
selection
OOS equity
summary
rolling performance
cost stress
capacity stress
parameter sensitivity
rule attribution
miss analysis
phase/theme/role attribution
diagnostics
reproducibility
```

标准 product run 和研究 artifact 边界明确，但前端可通过统一 API 查看摘要和链接。

## 十三、测试

覆盖：

- train/validation/test 隔离；
- 参数只从 validation 选择；
- 选择失败；
- fold 日历；
- OOS 拼接；
- 成本重执行；
- 规则对照不污染生产；
- 错过分类；
- PIT 题材/角色；
- 空池子；
- 数据缺失；
- 结果原子写入；
- compare/replay；
- 确定性和数据指纹。

## 十四、禁止范围

- 不自动发布“最优参数”；
- 不用 test 选择参数；
- 不因最近一个周期表现差就改规则结构；
- 不把后视题材周期用于历史决策；
- 不把回测成交等同 QMT 实盘成交；
- 不在本任务接入 QMT；
- 不用单一 Sharpe 作为唯一验收。

## 十五、验收

- 完整 System B 有可重复的全系统研究链；
- 关键规则、参数、成本和容量均有稳健性证据；
- 合法/非法错过可区分；
- 生产推荐参数来自独立验证并等待人工批准；
- 结果可比较、重放和审计；
- 专项、全量和研究 E2E 测试通过；
- PR 等待独立验收。
