> 任务 02 更新：2026-07-13，组合账户与 A 股现实回测相关 backtest 项已完成基础验收。

## 一、架构与工程

- [ ] `contracts → indicators → strategies` 单向依赖无反转；
- [ ] strategies 不访问数据库、不依赖 backtest；
- [ ] indicators 不输出交易动作；
- [ ] 通用 backtest 不包含具体策略知识；
- [ ] 未新增破坏 v1.0 封版边界的顶级模块；
- [ ] 公开接口有类型标注和必要文档；
- [ ] 无循环依赖；
- [ ] 全量测试、compileall、静态/格式检查通过；
- [ ] README 与真实代码能力一致。

## 二、数据和 contracts

- [ ] 本地数据库与 contracts 一致；
- [ ] 日线行情、复权、股票基础信息和交易日历覆盖稳定；
- [x] daily basic、涨跌停和停牌可用于回测；
- [ ] 财务三表和财务指标入库；
- [ ] 历史行业归属可按日期查询；
- [ ] 至少一类结构化事件可用；
- [ ] 财务和事件具有 published/available 时间；
- [ ] 修订记录不覆盖历史版本；
- [ ] 数据来源和入库时间可追溯；
- [ ] 回测查询不会返回未来才公开的数据；
- [x] 股票池不使用今天状态回看历史。
