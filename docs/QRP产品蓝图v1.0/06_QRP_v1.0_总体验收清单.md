# QRP v1.0 总体验收清单

> 任务 00 状态校准：2026-07-15。
> 说明：本清单区分 **已完成研究/底座项**、**产品剩余项** 与 **明确非发布门禁项**。
> 未完成的 07-B2 / 07-C / 07-D / 08 不因本校准被勾选为发布完成。

## 一、架构边界

- [x] 不新增顶级业务模块；
- [x] 依赖方向保持 `contracts → indicators → strategies → backtest/results → api/web`；
- [x] strategies 不访问数据库、不依赖 backtest 执行细节；
- [x] indicators 不输出交易动作；
- [x] backtest runtime / product 不硬编码具体策略逻辑到不可扩展状态；
- [x] 无破坏封版边界的循环依赖（以当前 main 审计为准，任务 08 再终检）。

## 二、数据与 PIT

- [x] 日线、复权、股票信息、交易日历稳定；
- [x] 财务三表和财务指标可查询；
- [x] 历史行业归属可按日期查询；
- [x] 历史指数成分可按日期查询；
- [x] v1.0 第一类标准事件可用：`earnings_forecast_event`（**不是**以泛化 `corporate_event` 为唯一验收对象）；
- [x] published / available / revision 语义正确（事件与财务/行业/指数 as_of）；
- [x] 修订不覆盖历史版本；
- [x] 数据来源、批次和入库时间可追溯（事件 pipeline manifest / 表字段）；
- [x] 历史查询不返回未来数据；
- [x] 股票池不使用今天状态回看历史。
