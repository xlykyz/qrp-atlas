## 1. 目标

在现有架构内建立可复用的横截面研究基础：

```text
某一交易日的历史股票池
→ 获取该日可用的多标的特征
→ 在同一交易日截面内进行清洗和标准化
→ 输出稳定、可审计、可供后续策略消费的横截面数据
```

本任务只建立基础能力，**不**实现正式横截面策略、Top N 选股、行业/市值中性化、多因子组合或组合调仓闭环。

## 3. 横截面数据约定

输入 / 输出至少包含：

| 字段 | 含义 |
|---|---|
| `trade_date` | 交易日 |
| `asset_id` | 资产标识 |
| 一个或多个特征列 | 调用方提供的待处理字段 |

统一规则：

- 所有算子按 `trade_date` **独立**执行，不跨日混合样本；
- 不使用未来日期数据；
- 不修改调用方传入的 DataFrame；
- 输出按 `(trade_date, asset_id)` 稳定排序（`mergesort`）；
- 空输入返回空 DataFrame，并尽量保留稳定列布局；
- 单标的截面有明确行为（rank=1；winsorize 保持原值；z-score 在样本不足时为 NaN）。

### 3.1 `trade_date` 标准类型

横截面 Frame、历史股票池和 `process_cross_section()` 对齐前，统一将 `trade_date` 规范为：

```text
timezone-naive pandas.Timestamp，normalize 到当天 00:00:00
```

接受输入：

- 字符串（如 `"2024-02-01"`）；
- `datetime.date` / `datetime.datetime`；
- naive 或 timezone-aware `pandas.Timestamp`。

同一天的不同表示必须映射为同一个值。
`trade_date` 是交易日标签，不是 UTC 事件时间：timezone-aware 输入在删除时区时**保留本地墙上日期**，不先转换到 UTC。例如 `2024-01-02 00:30:00+08:00` 规范为 naive `2024-01-02 00:00:00`，不会变成 `2024-01-01`。

多日期输入在规范化后做**确定性去重**，保持首次出现顺序。例如：

```python
["2024-01-02", date(2024, 1, 2), datetime(2024, 1, 2, 15, 0), pd.Timestamp("2024-01-02")]
```

只形成一个交易日。

无法解析或为空的日期显式抛出 `CrossSectionFrameError`。


### 3.2 `(trade_date, asset_id)` 主键约束

`(trade_date, asset_id)` 是真正的唯一键：

- `trade_date` 不得为空；
- `asset_id` 不得为空或空字符串；
- 同一 `trade_date + asset_id` 不得重复。

特征 Frame、调用方显式传入的 universe，以及 merge 前数据都必须遵守该约束。
检测到重复时显式抛出 `CrossSectionFrameError`，**不得**静默保留一行，也**不得**让 merge fan-out。

说明：`build_historical_universe()` 对自身生成结果可做确定性去重；但调用方传入的重复 universe 不得静默接受。

## 4. 横截面基础算子

```python
cross_section_rank(...)
cross_section_percentile_rank(...)
cross_section_winsorize(...)
cross_section_zscore(...)
apply_cross_section_operators(...)
```

### 4.1 rank

- 默认 `method="average"` 处理并列；
- `ascending=True` 时小值排名靠前，`False` 时大值靠前；
- 非有限值（NaN / ±inf）不参与排名，结果保持 NaN；
- 输出列：`{feature}_rank`。

### 4.2 percentile rank

- 使用 pandas `rank(pct=True)`；
- 值域为 `(0, 1]`；
- 输出列：`{feature}_pct_rank`。

### 4.3 winsorize

- `limits=(lower, upper)` 为分位数，要求 `0 <= lower < upper <= 1`；
- 在每个 `trade_date` 内，用有限样本估计分位并 clip；
- 非有限值保持 NaN；
- 单样本截面返回原值；
- 输出列：`{feature}_winsorized`。

### 4.4 z-score

- 默认 `ddof=0`（总体标准差），便于小样本截面；
- 默认 `min_count=2`：有效样本不足时整截面返回 NaN；
- 零方差截面返回 NaN，避免除零；
- 非有限值不进入 mean/std，并在输出中保持 NaN；
- 输出列：`{feature}_zscore`。

### 4.5 组合算子入口

```python
apply_cross_section_operators(
    df,
    feature_columns,
    operators=("rank", "pct_rank", "winsorize", "zscore"),
    ...
)
```

支持算子名：`rank`、`pct_rank`/`percentile_rank`、`winsorize`、`zscore`。

## 5. 历史股票池

```python
HistoricalUniverseRequest
HistoricalUniverseSource  # "explicit" | "index"
build_historical_universe(...)
resolve_historical_universe(...)
```

### 5.1 显式资产列表

```python
build_historical_universe(
    trade_dates,
    asset_ids=["A", "B"],
    source="explicit",
)
```

- 将资产列表笛卡尔展开到各 `trade_date`；
- 空资产列表返回空结果，**绝不**退化为全市场。

### 5.2 指数历史成分（PIT）

```python
build_historical_universe(
    trade_dates,
    index_code="000300.SH",
    source="index",  # 可省略，提供 index_code 时默认 index
    db_path=...,
)
```

规则：

- 直接复用 `query_index_components_as_of()`；
- 每个目标日期只使用当时已可用的指数快照；
- 首个可用快照之前返回空；
- 不同 `index_code` 严格隔离；
- 不根据当前成分反推历史，避免幸存者偏差；
- 结果稳定排序；指数路径可附带 `index_code` / `snapshot_date` / `weight`。

本任务**不**实现 ST、停牌、流动性、上市状态等完整过滤。

职责：

2. 将调用方特征按 `(trade_date, asset_id)` 对齐；

4. 返回稳定排序结果。
