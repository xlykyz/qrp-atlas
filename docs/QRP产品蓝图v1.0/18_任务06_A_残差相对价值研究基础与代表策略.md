## 3. 数学与时间语义

### 3.1 收益率

```text
asset_return[t] = close[t] / close[t-1] - 1
benchmark_return[t] = benchmark_close[t] / benchmark_close[t-1] - 1
```

不同资产独立计算，不做跨资产填充。

### 3.2 日期对齐

资产收益与 benchmark 收益只按完全相同 `trade_date` 精确对齐：

- 不向未来寻找 benchmark；
- 不 backward / forward fill；
- benchmark 当日缺失 → 该资产当日残差结果为 NaN，并记录 diagnostics；
- 重复 `(trade_date, asset_id)` 或重复 benchmark 日期直接拒绝。

### 3.3 Prior-only rolling OLS

对资产 `i` 在日期 `T`：

```text
r_i = alpha + beta × r_benchmark + epsilon
```

拟合样本严格为：

```text
[T-window, ..., T-1]
```

**T 日本身收益不参与 T 日模型拟合。**

样本外残差：

```text
residual_return[T]
= asset_return[T] - (alpha[T] + beta[T] × benchmark_return[T])
```

### 3.4 Residual z-score

```text
residual_zscore[T]
= (
    residual_return[T]
    - mean(residual_return[T-z_window : T-1])
  )
  / std(residual_return[T-z_window : T-1])
```

当前 residual 可被评价，但 **不得** 进入自身均值 / 标准差基准。

### 3.5 异常语义

以下情况输出 NaN，并给出稳定 diagnostics：

- 有效样本 < `min_periods`
- benchmark 历史方差为零
- 设计矩阵秩不足
- 当前 asset / benchmark return 缺失
- 非法日期或重复主键

不使用伪逆悄悄给出不可靠 beta。

## 4. 公开接口

### 4.1 指标

```python
from qrp_atlas.indicators import calculate_market_residuals
# 或
from qrp_atlas.indicators import IndicatorRequest, calculate_indicators
```

输出字段：

- `rolling_alpha`
- `rolling_beta`
- `rolling_r2`
- `residual_return`
- `residual_zscore`

参数化注册码：`market_residual`。

时间语义：T 日收盘后形成，最早用于下一交易日执行。

### 4.2 数据准备

```python
from qrp_atlas.backtest import prepare_market_residual_panel
```

负责：

- 资产 / benchmark 价格转收益；
- 精确交易日对齐；
- 生成 indicators 可消费面板；
- 记录 benchmark 身份与缺失 diagnostics。

benchmark 必须由调用方显式指定或注入，不在指标 / 策略内部硬编码指数代码。

### 4.3 策略

```text
code: market_residual_mean_reversion
version: 1.0.0
```

定位：

- long-only 研究策略；
- benchmark 只用于 residual signal；
- 组合实际只持有股票；
- **不代表** 已实现市场中性或完整配对交易。

主要参数：

- `entry_zscore`（负数，默认 `-2.0`）
- `exit_zscore`（默认 `-0.25`）
- `min_r2`
- `max_hold_days`
- `window` / `min_periods` / `z_window` / `fit_intercept`

ENTER：

```text
residual_zscore <= entry_zscore
AND rolling_r2 >= min_r2
AND alpha/beta/residual/zscore 有限
```

EXIT：

- `residual_zscore >= exit_zscore`
- `max_hold_days` 到期
- beta / R² / residual 指标失效或关系稳定性不足

### 4.4 原因码

- `RESIDUAL_EXTREME_ENTRY`
- `MEAN_REVERSION_EXIT`
- `MAX_HOLD_EXIT`
- `RELATIONSHIP_INVALID`
- `INSUFFICIENT_HISTORY`
- `MISSING_BENCHMARK`
- `INVALID_INDICATOR`
- `POSITION_CONTINUES`
- `ENTRY_CONDITION_NOT_MET`

Evidence 至少包含：

`signal_date`、`rolling_alpha`、`rolling_beta`、`rolling_r2`、`residual_return`、`residual_zscore`、benchmark 身份和关键策略参数。

### 4.5 研究入口

```python
from qrp_atlas.backtest import run_residual_research
```

返回：

- 完整 residual panel
- 可用样本数量
- 缺失 / 失败 diagnostics
- residual z-score 分组
- 各组未来收益
- 极端负 residual 组与其他组对比
- benchmark 与参数快照

未来收益只用于评价，不进入策略输入、选择条件或权重。

### 4.6 公开组合 runner

```python
from qrp_atlas.backtest import run_market_residual_mean_reversion_backtest
```

标准链：

```text
资产价格 + benchmark
→ prepare_market_residual_panel
→ get_strategy("market_residual_mean_reversion")
→ strategy.run(...)
→ strategy_decisions_to_target_weights(...)
→ shift_target_weights_to_execution_dates(next_open)
→ PortfolioBacktestEngine
```

执行语义：

- signal date = T（收盘后决策）
- execution date = T+1（默认 next_open）
- 末日无下一交易日信号进入标准 skipped
- warmup 只服务指标计算；正式结果不早于请求 `start_date`
- benchmark 不进入实际持仓
