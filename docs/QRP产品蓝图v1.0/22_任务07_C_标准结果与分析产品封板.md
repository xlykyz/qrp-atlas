## 本轮返修（相对复验阻塞）

1. **excess 数学口径**
   - `daily_active_return = (1+p)/(1+b)-1`（`excess_return` 同义别名）
   - `excess_percentage_point = portfolio_cum - benchmark_cum`
   - `relative_return = (1+port_cum)/(1+bench_cum)-1`
   - benchmark 日期缺口：**不跨缺口**汇总完整区间 excess total；summary 中 full-range 字段为 `None`，diagnostics 明示
2. **MAE/MFE 全路径**
   - 从 fills/orders 提取实际成交资产 → 加载 OHLC 持仓窗口 → writer 填充
   - 横截面不再依赖 `request.tickers` / 缺失 `price_frame`
3. **暴露命名诚实**
   - `position_concentration` 独立字段（position_count/max_weight/sum_weight）
   - `industry` / `market_cap` 使用 PIT 行业成员 + 当日市值加权 log_mcap（可得时）
   - 不可用时明确 `industry_available` / `market_cap_available=false`，**不**把集中度写入 market_cap
4. **可执行复现**
   - reproducibility 含 resolved universe、data fingerprints、product_request 锁定快照
   - `replay_product_run` + `POST /api/backtest/runs/{run_id}/replay`
   - 对比 summary/equity/orders/fills/trades/snapshot targets（允许 run_id/created_at 不同）
