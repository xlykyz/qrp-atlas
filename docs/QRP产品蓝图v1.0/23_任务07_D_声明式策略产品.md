## 目标

提供安全声明式策略能力：白名单规则、静态校验、不可变版本、owner 绑定，并通过现有真实回测产品链运行。

## 交付

- `strategies/declarative/store.py`：validate/create/list/get/new version/archive
- API：`/api/declarative-strategies/*`
- 产品目录合并内置与用户声明式策略
- 产品任务可引用锁定版本，run 后标记 `referenced_by_runs`
- 前端受控规则编辑器（无任意代码文本执行）
- 测试覆盖非法算子拒绝、版本不可变、owner 隔离、产品闭环、无 eval/exec 路径

## 安全边界

禁止 eval/exec/任意 Python/任意导入/动态函数调用。

- 目录 GET 支持声明式 code/version 解析
- 可选 HOLD 条件；indicator_requests 与 alias 唯一性校验
