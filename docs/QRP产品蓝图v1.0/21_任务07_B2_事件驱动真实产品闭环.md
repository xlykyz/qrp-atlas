# 任务 07-B2：事件驱动真实产品闭环

## 目标

将 `event_drift_basic` 接入真实回测产品主链：

```text
前端选择 event_drift_basic
→ 配置 hold_days / min_profit_change_midpoint / tickers / 区间 / 组合与成本
→ 创建真实任务
→ query_earnings_forecast_as_of + EventFrame
→ run_event_drift_portfolio_backtest
→ 标准产品结果包
→ 前端查看 / 刷新重开 / run 对比
```

## 关键语义

- 第一类事件：`earnings_forecast_event + EventFrame`
- 入场：`available_trade_date` open（产品层不二次 `next_open`）
- 同日公告不可成交
- 未来事件不进入历史任务 as-of 窗口
- 空事件区间：确定性现金结果
