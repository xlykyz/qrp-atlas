## 目标

将 `event_drift_basic` 接入真实回测产品主链：

```text
前端选择 event_drift_basic
→ 配置 hold_days / min_profit_change_midpoint / tickers / 区间 / 组合与成本
→ 创建真实任务
→ query_earnings_forecast_as_of(include_all_disclosures=True)
→ EventFrame
→ run_event_drift_portfolio_backtest
→ 标准产品结果包
→ 前端查看 / 刷新重开 / run 对比
```

## 关键语义

- 第一类事件：`earnings_forecast_event + EventFrame`
- 入场：`available_trade_date` open（产品层不二次 `next_open`）
- 同日公告不可成交
- 未来正式披露不进入历史任务 as-of 窗口
- 同一 `event_series_id` 的多次正式披露全部保留（`include_all_disclosures=True`）
- 每次正式披露仅保留当前库中 canonical technical revision（`include_all_revisions=False`）
- **不宣称** technical revision knowledge-as-of 隔离；结果快照记录实际使用的 `source_record_id` / `revision_id`
- 空事件区间：确定性现金结果
