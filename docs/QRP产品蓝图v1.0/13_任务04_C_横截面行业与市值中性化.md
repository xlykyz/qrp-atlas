## 3. Exposure Panel 契约

`prepare_cross_section_exposure_panel(...)` 输出列：

| 字段 | 含义 |
|---|---|
| `trade_date` | 横截面目标交易日 T |
| `asset_id` | 资产标识 |
| `industry_code` | T 日 PIT 行业代码 |
| `log_market_cap` | 同日市值的自然对数 |

规则：

- `(trade_date, asset_id)` 唯一；重复键显式报错；
- 稳定排序：`trade_date`, `asset_id`；
- 不修改调用方输入；
- 空股票池返回稳定空结构（保留四列）；
- 缺失行业 / 市值保留行并给 NaN / NA，不删除股票池行；
- 空 `industry_panel`（含 `pd.DataFrame()` 或仅表头）合法，输出完整股票池且 `industry_code` 全缺失；
- 注入的 industry query 若同一目标日同一资产返回多行，显式抛 `ExposurePanelError`，不得 `keep="last"`。

### 3.1 行业 PIT

- 默认分类：`sw2021`；
- 默认层级：一级行业（`industry_level=1`）；
- 每个目标交易日独立调用 `query_industry_as_of(as_of_date=T, ...)`，或消费注入的 `industry_query` / 预对齐 `industry_panel`；
- 仅使用 `T` 当日 as-of 可见的行业状态；
- 后续行业变更不得污染较早交易日；
- 同一目标日的股票池只做一次必要查询（按日期循环一次）。

### 3.2 市值

- 仅使用目标交易日 **同日** 可用的市值字段（默认 `market_cap`，可选 `float_cap` / `total_mv` / `circ_mv`）；
- `log_market_cap = ln(size)`，要求 size > 0 且有限；
- 零 / 负 / NaN / ±inf / 缺失 → NaN；
- **不**跨日前向填充；
- **不**使用未来市值。

## 4. 中性化模型

每个 `trade_date` 独立拟合，不跨日混合样本：

```text
factor = intercept + industry fixed effects + numeric exposures + residual
neutralized_factor = residual
```

### 4.0 因子级样本与设计矩阵

每个因子在每个 `trade_date` **独立**确定回归样本，再基于该样本构造设计矩阵：

```text
finite(factor) + 必需暴露有效
  → 实际回归样本
  → 仅用该样本生成行业类别与数值暴露
  → 满秩检查
  → OLS residual
```

因此：

- 一个因子的缺失模式不得影响另一个因子；
- “某行业在某因子上全部缺失”只会从该因子样本中消失，不会制造全零 dummy 污染其它行业；
- 缺失因子的资产残差为 NaN，其他可识别样本继续计算。

### 4.1 分类暴露（行业）

- 对每个分类列：
  - 类别按字典序稳定排序；
  - 与截距一起时 **drop first**（基准类）以避免虚拟变量陷阱；
  - 仅一个类别时不加 dummy，退化为截距 demean；
  - 缺失类别统一规范化为真正缺失，**不得**把 `pd.NA` 转成字符串 `"<NA>"`；
- 视为缺失：`None` / `np.nan` / `pd.NA` / `NaT` / `""` / 纯空格 / 字符串化 NA 标签；
- 缺失类别的资产不参与拟合，残差为 NaN。

### 4.2 数值暴露

- 默认 `log_market_cap`；
- 调用方可传入其他已准备好的数值暴露列（为未来 Beta 等预留接口，本任务不计算 rolling beta）；
- 非有限数值暴露标记该资产不可用。

### 4.3 联合中性化

支持：

- 仅行业；
- 仅市值（或其它数值暴露）；
- 行业 + 市值。

### 4.4 拟合与不可识别

- 使用最小二乘（`numpy.linalg.lstsq`）；
- 可用观测数 `n_obs < max(n_params, 2)` → 全部残差 NaN；
- 设计矩阵秩不足 / 奇异（如截距 + 常数市值）→ 全部残差 NaN；
- **不**使用伪逆静默“修好”共线；
- 恰好可识别且满秩时允许拟合（常数因子在满秩设计下残差 ≈ 0）；
- 非有限残差向量整体丢弃为 NaN。

### 4.5 缺失与输出语义

- 因子缺失 → 该资产残差 NaN；
- 必需暴露缺失 → 该资产残差 NaN；
- 未参与拟合的资产仍保留在输出中；
- 不因缺失删除股票池行；
- 原始因子列保留，不覆盖 `trade_date` / `asset_id`；
- 默认输出名：`{factor}_neutral`；
- 默认输出名由 `suffix` 控制（默认 `neutral` → `{factor}_neutral`）；
- 可通过 `output_columns` 指定别名，但禁止与以下冲突：
  - 保留字段 `trade_date` / `asset_id`；
  - factor frame 任意已有列；
  - exposure panel 任意已有列；
  - `categorical_exposures` / `numeric_exposures`；
  - 其他输出列；
- 同一字段不得同时作为 categorical 与 numeric exposure。

## 5. 与 04-A / 04-B 衔接

推荐处理顺序：

```text
原始因子
→ 可选 winsorize
→ 行业 / 市值中性化
→ z-score / rank
```

组合示例：

```python
from qrp_atlas.backtest import prepare_cross_section_exposure_panel
from qrp_atlas.indicators import (
    generate_factor_frame,
    neutralize_factor_frame,
    process_cross_section,
)

raw = generate_factor_frame(
    ["momentum", "roe", "book_to_price"],
    universe=universe,
    prices=prices,
    size_panel=size_panel,
    financial_panel=financial_panel,
)

exposure = prepare_cross_section_exposure_panel(
    universe,
    size_panel=size_panel,
    industry_panel=industry_panel,  # 或 industry_query / db_path+con
)

neutral = neutralize_factor_frame(
    raw,
    exposure_panel=exposure,
    factor_columns=["momentum", "roe", "book_to_price"],
    categorical_exposures=["industry_code"],
    numeric_exposures=["log_market_cap"],
)

processed = process_cross_section(
    neutral,
    feature_columns=["momentum_neutral", "roe_neutral", "book_to_price_neutral"],
    operators=("winsorize", "zscore", "rank"),
)
```

中性化本身 **不** 隐式执行 rank / winsorize / z-score。

覆盖：

- 行业 + 市值联合回归与多因子一次处理；
- 多交易日完全隔离；
- 行业 PIT：未来变更不污染旧日；查询按日一次；
- 同日市值、不前向填充；
- 缺失行业 / 市值 / 因子保留行并返回 NaN；

- `pd.NA` 行业不会形成 `"<NA>"` 类别；空 industry panel 输出全缺失行业；
- 输出名与 exposure 列冲突、categorical/numeric 重叠、query 同资产多行业、suffix 生效；
- 单一行业 demean；常数市值导致秩不足 → NaN；
- 常数因子在可识别设计下残差 ≈ 0；
- 重复主键显式失败；保留输出列冲突失败；
- 输入不可变；结果可继续 `process_cross_section()`；
- `indicators` 源码不导入 backtest / 不含 `db_path`；
- 空股票池稳定结构；非有限输入 → NaN。
