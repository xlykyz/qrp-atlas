## 1. 目标

在 04-A 横截面数据契约之上，建立正式、可复用、无未来函数的因子生成能力：

```text
历史股票池
→ 获取目标交易日当时可用的数据
→ 生成原始因子值
→ 输出唯一、稳定的 factor frame
→ 交给 04-A 横截面算子处理
```

本任务只负责因子定义与生成，不负责选股、权重或回测策略。

## 3. Factor Frame 契约

输出至少包含：

- `trade_date`
- `asset_id`
- 明确命名的因子列

并遵循 04-A 契约：

- `trade_date` 统一为 timezone-naive 午夜 Timestamp；
- `(trade_date, asset_id)` 唯一且非空；
- 稳定排序：`trade_date`, `asset_id`；
- 不修改调用方输入；
- 空股票池 / 空日期返回稳定空结构（保留列）；
- 非法值和缺失值使用 NaN，不得隐式填零。

数据层次区分：

| 层次 | 含义 | 本任务 |
|---|---|---|
| 原始数据字段 | close / market_cap / roe / bps 等 | 输入 |
| 原始因子值 | momentum / log_market_cap / roe / book_to_price | **输出** |
| 横截面标准化结果 | rank / winsorize / z-score | 复用 04-A |

## 4. 正式因子族

### 4.1 动量因子 `momentum`

- **公式**：`close[T] / close[T - lookback] - 1`
- **输入字段**：`close`（价格面板，支持 `asset_id` 或 `ticker`）
- **参数**：`lookback`（整数，默认 20，最小 1）
- **方向**：越大 = 近期涨幅越强（winner）
- **时间可用性**：
  - 只使用 `trade_date <= T` 的 bar；
  - **包含 T 日收盘**；
  - 因此只在 T 收盘后可知，面向 **T+1 或之后执行**。
- **窗口不足**：按资产独立累计 bar；可用 bar 少于 `lookback + 1`，或端点非正 / 非有限 → NaN。
- **隔离**：不同资产价格序列绝不串联；不按全表位置跨资产计算。
- **默认输出列**：`momentum`；非默认 lookback 时为 `momentum_lookback_{N}`（可 alias）。

### 4.2 市值因子 `log_market_cap`

- **公式**：`ln(field[T])`
- **输入字段**（contracts 已有）：
  - 默认 `market_cap`（`daily_market_snapshot` / PriceFrame）
  - 可选 `float_cap`、`total_mv`、`circ_mv`（`daily_basic` 字段）
- **参数**：`field` ∈ `{market_cap, float_cap, total_mv, circ_mv}`，默认 `market_cap`
- **方向**：越大 = 公司规模越大
- **时间可用性**：仅使用同一 `trade_date = T` 的市值记录；不做跨日前向填充。
- **NaN 语义**：零、负、NaN、±inf → NaN；缺失当日记录 → NaN。
- **默认输出列**：`log_market_cap`

### 4.3 质量因子 `roe`（财务 PIT）

- **公式**：`financial_indicator.roe` 在目标日 T 的最新可用报告
- **输入字段**：`roe`、`available_trade_date`、`report_period`（及版本字段）
- **方向**：越大 = 质量越好
- **时间可用性**：
  - 仅 `available_trade_date <= T`；
  - 同一 `(asset, report_period)` 复用 `select_latest_available_records` 做版本选择；
  - 再在剩余报告中取最新 `report_period`；
  - 后续公告 / 修订不得污染更早交易日。
- **NaN 语义**：无合格报告、或 ROE 非有限 → NaN；不伪造字段。
- **默认输出列**：`roe`

### 4.4 价值因子 `book_to_price`（财务 PIT）

- **公式**：`financial_indicator.bps[as_of T] / close[T]`
- **输入字段**：`bps`（PIT）、`close`（同日）
- **方向**：越大 = 更便宜（value）
- **时间可用性**：
  - BPS 按 `available_trade_date <= T` + PIT 版本选择；
  - 价格使用 T 日收盘（与动量相同，面向收盘后 / T+1）。
- **NaN 语义**：BPS 或 close 缺失 / 非有限 / 非正 → NaN。
- **默认输出列**：`book_to_price`

## 6. PIT 与审计语义

必须区分：

| 概念 | 含义 |
|---|---|
| 行情数据日期 | 价格 / 市值面板的 `trade_date` |
| 财务报告期 | `report_period` |
| 财务 `available_trade_date` | 该版本在回测中最早可使用的交易日 |
| 横截面 `trade_date` | 因子截面日 T |

目标交易日 T 的财务因子：

```text
available_trade_date <= T
```

同一报告多次修订时，复用任务 03 的 `select_latest_available_records` 版本选择逻辑。  
开发与测试使用内存 fixture / 临时 DuckDB / 可注入 `financial_query`，不依赖 Linux 全量回填是否完成。
