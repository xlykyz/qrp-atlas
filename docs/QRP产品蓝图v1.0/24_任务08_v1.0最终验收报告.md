## 七、已知边界

以下边界已明确，不构成本次 v1.0 发布阻塞：

1. **Replay 语义**：保存锁定请求、策略定义快照、股票池和数据指纹，但不保存完整历史输入副本；replay 在当前代码和当前数据库上重跑，并诚实报告定义/数据是否仍匹配。
2. **指标版本**：标准结果保存指标请求、alias、参数绑定和输出身份；指标计算注册表尚未为每个实现建立独立语义版本号，当前实现身份随应用代码版本管理。
3. **部署形态**：策略、任务和结果仍为本地文件持久化，具备跨进程文件锁和原子替换，但不是分布式存储或多节点事务系统。
4. **交易范围**：v1.0 聚焦 A 股 long-only；short、借券、保证金、多腿同步成交、期权、HFT 和实盘下单不在范围内。
5. **事件范围**：以 `earnings_forecast_event` 为第一类标准事件；更多事件源与泛化事件主表属于后续版本。
6. **稳健性范围**：代表性残差策略具备完整稳健性研究；全策略通用参数优化/稳健性平台延后 v1.1。
7. **前端性能**：生产构建通过，但 bundle 仍有进一步 code-splitting 空间。
8. **旧结果兼容**：无 owner 字段的历史 fixture/旧结果仅允许默认本地用户读取，不向数据库认证用户开放。
