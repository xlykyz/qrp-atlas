## 2. 事件指标

实现位置：`src/qrp_atlas/indicators/events/`  
已注册到 indicators registry。

| 指标 code | 公式 / 语义 |
|---|---|
| `profit_change_midpoint` | `(profit_change_min + profit_change_max) / 2` |
| `profit_change_range` | `profit_change_max - profit_change_min` |
| `net_profit_midpoint` | `(net_profit_min + net_profit_max) / 2`（万元） |
| `net_profit_range` | `net_profit_max - net_profit_min`（万元） |
| `direction_score` | 预告类型映射：`+1 / 0 / -1` |
| `event_age` | 当前交易日距 `available_trade_date` 的开市日数；当日为 0 |
| `event_window` | `0 <= event_age < window_days` |

缺失区间任一端点：midpoint/range 返回 `NaN`。  
**不使用** `last_parent_net` 计算 surprise。  
不新增指标数据库表。

### 2.1 forecast_type → direction_score

真实样本来源：`forecast_vip(period=20231231)` 观测类型：

```text
预增, 略增, 扭亏, 续盈, 预减, 略减, 续亏, 首亏, 不确定
```

映射：

| 类型 | score |
|---|---:|
| 预增 / 略增 / 扭亏 / 续盈 / 首盈 / 减亏 | +1 |
| 预减 / 略减 / 续亏 / 首亏 | -1 |
| 不确定 / 持平 / 预警 | 0 |
| 未知类型 | 0，并写入 diagnostics，**不得**静默判正 |

### 3.1 forward return 口径

```text
entry_date  = available_trade_date
entry_price = open[entry_date]

horizon = N:
  available_trade_date 计作第 1 个交易日
  exit_price = close[第 N 个交易日]

forward_return_N = exit_price / entry_price - 1
```

缺 entry open / exit close / 完整未来窗口：

- 返回 `NaN`
- diagnostics 记录
- 不静默删样本，不扩展数据区间

## 4. 策略 `event_drift_basic`

注册位置：`strategies` registry。

参数：

| 参数 | 默认 | 说明 |
|---|---:|---|
| `hold_days` | 5 | 合法交易日持有期（含入场日为第 1 日） |
| `min_profit_change_midpoint` | 0.0 | 最低利润变动中枢 |
| `max_positions` | 50 | 最大同时持仓名数 |
| `max_weight_per_asset` | 1.0 | 单票权重上限 |

交易语义：

- 仅做多
- 仅 `direction_score > 0`
- 入场日 = 05-A `available_trade_date`（**不再** next_open）
- 入场价 = 当日 open
- 同票同日只保留确定性最新正式披露
- 多股票同时触发等权
- 不做行业/市场中性、空头、复杂调仓

时间语义：

```text
announcement_date = 事件证据日期
available_trade_date = 实际入场日期
trade_date >= available_trade_date
trade_date > announcement_date
```
