## 2. 事件指标

实现位置：`src/qrp_atlas/indicators/events/`
已注册到 indicators registry。

| 指标 code | 公式 / 语义 |
|---|---|
| `profit_change_midpoint` | `(profit_change_min + profit_change_max) / 2` |
| `profit_change_range` | `profit_change_max - profit_change_min` |
| `net_profit_midpoint` | `(net_profit_min + net_profit_max) / 2`（万元） |
| `net_profit_range` | `net_profit_max - net_profit_min`（万元） |
| `direction_score` | 预告类型映射：`+1 / 0 / -1` |
| `event_age` | 当前交易日距 `available_trade_date` 的开市日数；当日为 0 |
| `event_window` | `0 <= event_age < window_days` |

缺失区间任一端点：midpoint/range 返回 `NaN`。
**不使用** `last_parent_net` 计算 surprise。
不新增指标数据库表。

### 2.1 时间元数据

事件指标注册为：

```text
UpdateFrequency.REALTIME
allow_intraday_decision = True
```

说明：自 `available_trade_date` **开盘前**即可用于决策（入场价取当日 open）。
不得标记为 `AFTER_CLOSE`，避免产品层再次将信号延迟一日。

### 2.2 forecast_type → direction_score

真实样本来源：`forecast_vip(period=20231231)` 观测类型：

```text
预增, 略增, 扭亏, 续盈, 预减, 略减, 续亏, 首亏, 不确定
```

映射：

| 类型 | score |
|---|---:|
| 预增 / 略增 / 扭亏 / 续盈 / 首盈 / 减亏 | +1 |
| 预减 / 略减 / 续亏 / 首亏 | -1 |
| 不确定 / 持平 / 预警 | 0 |
| 未知类型 | 0，并写入 diagnostics，**不得**静默判正 |

### 3.1 forward return 口径

```text

  available_trade_date 计作第 1 个交易日

forward_return_N = exit_price / entry_price - 1
```

缺 entry open / exit close / 完整未来窗口：

- 返回 `NaN`

- 不静默删样本，不扩展数据区间

## 4. 策略 `event_drift_basic`

注册位置：`strategies` registry。版本：`1.0.2`。

### 4.1 策略参数（仅选股 + 持有期）

| 参数 | 默认 | 说明 |
|---|---:|---|
| `hold_days` | 5 | 合法交易日持有期（含入场日为第 1 日） |
| `min_profit_change_midpoint` | 0.0 | 最低利润变动中枢 |

**不再**由策略参数持有 `max_positions` / `max_weight_per_asset`（避免与组合配置双套冲突）。

### 4.2 仓位 / 等权职责

| 层级 | 职责 |
|---|---|
| 策略 | 选股、HOLD 窗口、EXIT 时点；ENTER/HOLD 的 `weight=None` |
| 策略 + `runtime_context["max_positions"]` | 入场时容量门禁（当日先 EXIT 再按分数接纳 ENTER）；拒绝项只记 diagnostics，**不**进入 active，避免延迟入场 / 提前挤仓 |
| `PortfolioBacktestConfig` | 容量配置唯一来源（runner 注入 `max_positions`）；`max_weight_per_asset` |
| `strategy_decisions_to_target_weights` | 对**全量并发持仓**等权，并应用单票上限 |

同日决策排序优先级：`EXIT → ENTER → HOLD`（不得依赖枚举字符串序）。

### 4.3 交易语义

- 仅做多
- 仅 `direction_score > 0`
- 入场日 = 05-A `available_trade_date`（**不再**额外 next_open）
- 入场价 = 当日 open
- 同票同日只保留确定性最新正式披露
- 多股票并发持仓由组合适配器等权
- 不做行业/市场中性、空头、复杂调仓

### 4.4 持有与退出（可执行口径）

```text
入场日计第 1 个持有交易日
持满 N 个交易日
下一交易日 open 退出

exit_index = entry_index + hold_days

例：
hold_days=1, entry=D0 → exit=D1 open
hold_days=5, entry=D0 → exit=D5 open
```

循环顺序：先处理当日 EXIT，再处理当日 ENTER，避免同 bar 买卖。

时间语义：

```text
announcement_date = 事件证据日期
available_trade_date = 实际入场日期
trade_date >= available_trade_date
trade_date > announcement_date
```

## 5. 公开回测入口

事件策略**不得**走 `prepare_strategy_data(price_df)` 的价格面板 + legacy 指标计算链。

稳定公开入口：

```python
from qrp_atlas.backtest import run_event_drift_portfolio_backtest

run = run_event_drift_portfolio_backtest(
    events,          # EventFrame from 05-A as_of / projection
    price_df,
    config,          # PortfolioBacktestConfig owns capacity
    trading_days=...,
    parameters={"hold_days": 5, "min_profit_change_midpoint": 0.0},
)
```

合约强制：

- `config.execution.price_field` **必须**为 `"open"`，否则 runner 直接报错
- `config.max_positions` 注入策略 `runtime_context`，在入场侧生效

内部路径：

```text
query_earnings_forecast_as_of / EventFrame
→ get_strategy("event_drift_basic")
→ strategy.run(
      prepared_data=events,
      runtime_context={open_dates, max_positions=config.max_positions},
  )
→ strategy_decisions_to_target_weights(
      max_positions=config.max_positions,
      max_weight_per_asset=config.max_weight_per_asset,
      default_weight=None,  # equal-weight concurrent book
  )
→ PortfolioBacktestEngine(price_field=open)
→ 标准组合结果
```
