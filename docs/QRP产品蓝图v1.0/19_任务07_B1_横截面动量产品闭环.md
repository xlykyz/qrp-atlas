# 任务 07-B1：横截面动量真实产品闭环

## 目标

将任务 04 的横截面研究能力接入任务 07-A 的真实回测产品主链，产品化：

```text
cross_sectional_momentum_long_only
```

用户路径：

```text
选择 cross_sectional_momentum_long_only
→ 选择历史指数成分股票池（index_code）
→ 设置动量窗口、Top N、调仓频率和组合约束
→ 创建真实回测任务
→ 后端按历史股票池和 PIT 语义运行
→ PortfolioBacktestEngine 执行
→ 保存标准结果包
→ 前端查看任务、净值、回撤、交易和配置
```

## 历史股票池 PIT 语义

- 新增 `universe_mode=index_components` + `index_code`
- 每个调仓信号日通过既有 `build_historical_universe` / `query_index_components_as_of`
- 禁止使用当前成分回看历史、禁止全市场回退、禁止静态 ticker 回退
- 空历史成分日：空目标 / 诊断，不扩展股票池

## 因子时间语义

- 复用任务 04 `generate_factor_frame` + `momentum` 正式因子
- `momentum = close[T] / close[T-lookback] - 1`
- 只使用信号日及以前价格；预热可早于 start date
- 正式决策、订单、成交、净值不早于 start date

## signal → execution

- 策略 rebalance schedule 负责唯一一次 `signal_date → trade_date(next open)` 映射
- 产品层对横截面路径 **不再** 二次 `next_open` 偏移
- 只过滤执行日落在请求区间外的信号，写入 `NO_EXECUTION_DATE_IN_RANGE`
- 仅支持 `entry_timing=next_open`

## 参数 SSOT

- 策略参数：`momentum_lookback`、`top_n`、`rebalance_frequency`、`cash_buffer`、`ascending`
- 组合配置：`initial_cash`、`max_positions`、`max_weight_per_symbol`、成本
- 产品层将组合配置同源覆盖到策略的 `max_positions` / `max_weight_per_asset`
- 校验 `top_n <= max_positions`

## 公开产品入口

```python
run_cross_sectional_momentum_product_backtest(request, db_path=...)
```

标准链：

```text
请求
→ 参数解析
→ 交易日与调仓计划
→ PIT 历史股票池
→ 价格与动量因子准备
→ get_strategy("cross_sectional_momentum_long_only")
→ strategy.run(...)
→ strategy_decisions_to_target_weights(emit_unchanged_snapshots=True)
→ PortfolioBacktestEngine
→ BacktestRunWriter
```
