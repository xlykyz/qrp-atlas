## 3. Forward return

```python
compute_forward_returns(...)
```

```text
forward_return_h[T] = price[T+h] / price[T] - 1
```

- `T+h` 基于全市场真实交易日历；
- 单资产缺日不得把更远日期当作 T+h；
- 非正 / 非有限 / 缺失 → NaN；
- 不前向填充；
- 默认 horizon：1 / 5 / 20。

## 12. 返修说明（PR #15）

- `run_cross_section_research` 唯一参数源：`get_strategy → 合入 convenience args → resolve_parameters`。
- convenience 优先级：显式 run 参数 > `strategy_parameters` > strategy definition 默认值。
- 只注入策略 schema 声明的参数；`score_column` 不会进入 `multifactor_long_only`。
- research schedule 与 strategy / exposure 映射共用同一 resolved 参数（含 `explicit_dates_json`）。
- `analyze_target_exposures` 严格校验 target key 唯一、权重大于等于 0、有限、日内正权和不超过 1；schedule 的 signal/trade 唯一且 `trade > signal`；mapping 仅支持 `signal_date → trade_date`。
- 分类暴露权重和不得超过当日正目标总仓位。
- 少于两个不同组时 `spread_return = NaN`。
- 空 `factor_frame` 不扩展为全市场价格宇宙，diagnostics 记录 `empty_factor_universe`。
