# `users/` Agent Rules

本目录负责 QRP 的内部用户实体、状态和用户资料。

## 职责

- 定义稳定的内部 `user_id`；
- 定义用户状态和基础资料；
- 提供用户 Repository 与 Service；
- 为认证层和用户归属业务提供统一用户模型。

## 边界

- 不处理密码、Token、Cookie、JWT 或会话；
- 不感知 Supabase、Clerk 等具体认证供应商；
- 不保存复盘、自选股、策略配置或回测结果；
- 不依赖 `auth/`，避免用户领域反向依赖认证机制；
- 不依赖量化核心模块。

PostgreSQL 中的用户表属于身份控制面；用户绑定的 QRP 业务数据继续存储在 DuckDB，通过内部 `user_id` 建立归属。跨库关系由应用层保证，不建立伪造的跨库外键。
