# `src/qrp_atlas/indicators` Agent Rules

本文件适用于 `src/qrp_atlas/indicators/` 及其全部子目录，并与上级 [`src/qrp_atlas/AGENTS.md`](../AGENTS.md) 同时生效。

QRP v1.0 的指标与因子边界见：

- [`docs/核心架构v1.0/QRP_v1.0_核心架构文档.md`](../../../docs/核心架构v1.0/QRP_v1.0_核心架构文档.md)
- [`docs/核心架构v1.0/QRP_v1.0_指标与因子边界补充说明.md`](../../../docs/核心架构v1.0/QRP_v1.0_指标与因子边界补充说明.md)

## 正式定位

`indicators` 是 QRP 的量化指标、特征与因子计算层。

```text
Factor ⊂ Indicator
```

因子是用于比较、排序、过滤、评分或模型输入的一类指标，不是独立顶级架构层。不得新增与 `indicators` 平行的 `qrp_atlas.factors` 模块。

本层回答：

> 市场、题材或标的已经发生了什么？

不回答：

> 应当交易什么、交易多少、何时买卖？

## 允许内容

- 基础指标：收益率、均线、斜率、波动率、回撤、成交额和换手率等；
- 状态事实：趋势有效、连续运行天数、涨停次数、异常状态等；
- 原始因子：动量、规模、价值、质量、相对强度等；
- 横截面算子：rank、percentile、winsorize、z-score；
- 行业、市值和其他客观暴露的中性化结果；
- 题材数量、占比、集中度、扩散度和持续性等聚合事实；
- 固定定义、可跨策略复用、不包含交易授权的组合指标或组合因子；
- 指标与因子的元数据、参数校验、时间语义、方向和 NaN 语义。

## 禁止内容

- 数据库、网络或 pipeline 访问；
- PIT 财务版本选择和目标日期查询；
- 策略专属权重、阈值和综合评分偏好；
- 硬门槛、绝对否决权、Top-N 和目标权重；
- ENTER、HOLD、EXIT、NO_ACTION 等交易动作；
- 持仓、仓位、资金、成交、成本和收益；
- forward return、IC、Rank IC、因子分组未来收益；
- 使用未来数据参与历史因子值计算；
- 为单个策略复制已有指标或因子算法。

## 组合结果的归属判断

一个组合结果只有同时满足以下条件时才属于 `indicators`：

1. 只使用当时可用的数据；
2. 输出是客观数值或状态，不是交易动作；
3. 定义固定且可被多个策略复用；
4. 不包含具体策略的准入、否决、仓位或排序偏好。

若权重、阈值或组合方式表达某个策略的交易偏好，则应放入 `strategies`。

## 数据准备边界

`indicators` 只消费调用方已经准备好的 DataFrame 或明确结构化输入。

- 原始字段必须复用 `qrp_atlas.contracts`；
- 多版本财务、行业和指数成分的 PIT 选择由 pipeline 或 backtest runtime 负责；
- 已对齐面板可以进入指标计算，但指标模块不得反向导入 `backtest`；
- 输出日期必须明确可用时点，避免把 T 日收盘后才可知的值用于 T 日成交。

## 实现要求

- 优先复用已有计算函数和横截面算子，不得重复实现；
- 计算函数应确定、无副作用，不修改调用方输入；
- 参数、输出列和 alias 必须稳定且可校验；
- 明确窗口、公式、方向、时间语义和缺失值语义；
- 非有限值不得静默填零；
- 多资产计算不得串联历史；
- 横截面输出应保持唯一 `(trade_date, asset_id)` 和稳定排序；
- 新因子应优先接入现有 factor registry 或 indicator calculation registry，不为单一实现创建平行注册体系。

## v1.0 兼容约束

当前以下接口允许并存：

```text
IndicatorDefinition / IndicatorRequest
FactorDefinition / FactorRequest
```

不得仅为概念统一而在 v1.0 重写已工作的注册、策略或回测链路。内部抽象统一、依赖 DAG、缓存、血缘和前端因子工作台属于 v1.1 可评估范围。

## 测试要求

新增或修改指标、因子时至少覆盖：

- 单资产与多资产隔离；
- 日期排序与窗口边界；
- 缺失值、非有限值和非法输入；
- 空股票池与部分缺数据；
- 输入不可变和输出稳定；
- 无未来数据泄漏；
- 参数、alias、输出列冲突；
- 横截面主键唯一性；
- 与现有公开入口和策略消费方式兼容。
