# `auth/` Agent Rules

本目录负责确认请求者身份，并将身份解析为稳定的内部 `UserContext`。

## 职责

- 认证 Provider 抽象与实现；
- 密码哈希与验证；
- 登录会话签发、解析、撤销；
- FastAPI 当前用户依赖；
- 外部身份与内部用户的连接入口。

## 边界

- 可以依赖 `users/` 获取内部用户及状态；
- 不保存复盘、自选股、策略配置、回测任务等 QRP 业务数据；
- 不依赖 `contracts`、`indicators`、`strategies` 或回测执行引擎；
- 不在路由中复制认证算法；
- 不明文保存密码或会话 Token；
- 数据库认证失败或 PostgreSQL 不可用时，禁止自动降级为本地用户。

## 运行模式

- `local` 是正式的单用户运行模式，必须完全跳过 PostgreSQL；
- `database` 必须显式启用，并严格执行数据库认证；
- 新认证服务应通过新增 Provider 接入，不让业务模块依赖具体供应商。
